# Proyecto-Scrum-Implementaci-n-de-la-Red-DPT

El presente proyecto tiene como finalidad diseñar, documentar e implementar una infraestructura de red
empresarial para la empresa **DOÑA PANCH TECH**, garantizando una red segura y escalable.
Se realizará el direccionamiento IPv4 e IPv6, la segmentación mediante VLANs, la configuración
de acceso remoto por SSH y la documentación técnica correspondiente, acompañada de pruebas
de conectividad que validen el correcto funcionamiento de la solución.

Requerimientos de la empresa DOÑA PANCH TECH:

→ Configuración en dispositivos.
→ Configurar switches con VLANs y VTP.
→ Configurar direccionamiento IPv4 / IPv6 en routers y PCs.
→ Habilitar SSH para administración segura.
→ Configuración de Inter-VLAN Routing.
→ Dispositivos configurados y funcionando.
→ Pruebas de conectividad IPv4 e IPv6.
→ Pruebas de acceso por SSH.
→ Validación de VTP y VLANs.

El proyecto se estara realizando bajo la metodologia SCRUM, siendo llevado a cabo por Melanie Gómez (Scrum Master) líder del grupo de redes junto a su equipo de desarrolladores (DevTeam), Oscar Mesa y Franklin Mendrano.
